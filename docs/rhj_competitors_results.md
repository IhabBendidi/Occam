# RHJ competitor results

See the [current five-seed comparison](../data/release/official_comparisons/rhj_fewshot__all.md).
Each training seed is evaluated on five split-half partitions. Reported uncertainty
is the sample standard deviation across the five training-seed means.

[Reproduction commands](../scripts/repro/README.md) cover Occam, all four competitors,
and the reference baselines. All official Occam models use GO, STRING, GenePT, and ESM2.
