_Generated by `scripts/norman/write_competitor_seed_report.py` from `data/release/metrics/norman_competitors_by_seed_split.csv`. Do not edit by hand; re-run the script._

## Protocol

| | |
|---|---|
| benchmark | `norman_combo` — Norman 2019 K562 CRISPRa, rebuilt from GEO GSE133344 |
| task | train on 105 single-gene conditions; predict 111 held-out double pairs whose two genes were each seen singly |
| axis | 8,000 genes, sha256 `6efa91af1af5c8b8…` — identical for every arm and for Occam |
| scored panels | `additive` and `nonadditive`, 36 pairs each, **effect-size-controlled** (additivity residual terciled within effect-size terciles) |
| protocol | paired split-half: half A is the reference, half B the target, the model is fed half-B controls; 5 seeded splits |
| scorer | cell-eval 0.6.0, `nocal` (no calibration) |
| replication | seeds 42–46, **5 splits per seed**. Seed is the unit of replication: each seed's value is the mean of its 5 splits, and every SD / SEM below is ACROSS SEEDS |

| arm | how it composes a pair | seeds |
|---|---|---|
| TxPert | native additive sum of the two perturbation embeddings | 42, 43, 44, 45 (n=4) |
| CellFlow | native set aggregation, max_combination_length=2 | 42, 43, 44, 45, 46 (n=5) |
| State | decode_seq_mean at the export boundary (our extension of its consecutive forward passes) | 42, 43, 44, 45, 46 (n=5) |

**Direction.** Higher is better except `mae`, `mse`, `mae_delta`, `mse_delta` (ERRORS, lower better). `discrimination_score_*` has chance at 0.5. `de_nsig_counts_*` and `n_perturbations` are counts, not quality, and must not be ranked on.
