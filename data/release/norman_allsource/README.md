# Norman all-source release: NF32ALLA

This directory contains only the published NF32ALLA model, training seeds 42–46,
five evaluation splits per seed, and all seven Norman evaluation subsets.
The `middle` subset contains intermediate biological responses; it is part of the
published evaluation and is retained along with the full set and both additive subsets.

Retired NF32ALL experiments are excluded. The retained score values are unchanged.
See `data/release/official_comparisons/` for comparisons with competitors, baselines,
and experimental reproducibility.
